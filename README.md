# 🎮 Tic-Tac-Toe Game (C++ Console)

This is a simple **2-player Tic-Tac-Toe game** implemented in C++. Players take turns entering cell numbers to place their `X` or `O` on a 3x3 board. The game checks for a win or draw after every move.

---

## 🧠 Features

- 3x3 interactive board
- Input-based cell selection
- Win and draw detection
- Turn-based player switching

---
